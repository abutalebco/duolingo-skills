# Cantonese (粵語) — worksheet guide

| Field | Value |
|---|---|
| Code | yue |
| Script | Hanzi (Traditional, Hong Kong forms) |
| Direction | left-to-right |
| Reading aid | Jyutping |
| Typst fonts | Noto Sans CJK HK (+ DejaVu Sans fallback) |
| Typst lang/region | zh/HK |
| Cell grid | Yes (1 character per cell, tian-zi style) |
| Duolingo status | verify on duolingo.com/courses before building (newer/incubator/limited course) |

## Teach and drill (pick content from here)

- Jyutping with tone numbers 1–6 (e.g. nei5 hou2)
- Spoken-only particles and characters (嘅, 咗, 喺, 唔, 哋)
- Colloquial written Cantonese vs Standard Written Chinese: choose colloquial for speech practice

## How to fill entries

`text` = Traditional hanzi in colloquial Cantonese. `reading` = Jyutping. `meaning` = English.

## Pitfalls

- Do not reuse Mandarin pinyin; readings are Jyutping
- Use Traditional characters (HK forms)
- Verify Duolingo currently offers this course; if not, still allowed (real language) but note the status

## Layout behaviour

- Words: first row = faded copies of the word, then blank cells; `rows` adds more blank rows.
- Sentences: for every row of characters, a faded row followed by a blank row directly beneath it.

## Starter section ideas

Greetings & introductions · Numbers 1–20 · Food & drink · Family · Places & directions · Time & days · Everyday verbs · Short sentences / mini dialogues

- Same grid rules as Mandarin (tian zi ge, 1 character per cell). Set `lang` zh / region HK for correct glyph variants.


## Quality checklist

- Every `text` is natural and correct; no machine-looking literal translations.
- Diacritics/special letters verified (see Pitfalls).
- Fonts render every glyph (no tofu boxes) — preview page 1 before delivering.
- Sentences are short, useful, and reuse words from earlier sections.
